## Cross-cell decisions

Decisions that affect other cells will be presented in the architecture forum and documented in the meeting notes. If there is no agreement, the Architecture office decides.

## Salesforce API budget

We will review our consumption every month with the Salesforce platform team, and ask for more budget if needed. For Mexico we already know we need more before the month-end peaks grow (see `ARCHITECTURE.md`, section 5).
